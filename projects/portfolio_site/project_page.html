Portfolio Website

Tags: html, css, java-script, github-pages, website

This website, which I built my portfolio on, is hosted using GitHub Pages. Previously, I used a Google Drive folder containing the necessary files as my portfolio, which meant that everything had to be downloaded as separate PDF files before it could be reviewed. I am glad I switched to a portfolio website instead, as it gives me much more flexibility in how I present and share my work. It also allows visitors to decide which projects they want to explore in more depth, rather than having to go through one long, static PDF file.

...

The site is based on a template I found on GitHub. It is a simple template that gave me a good starting point and the opportunity to refresh my knowledge of HTML, CSS, and JavaScript, which I had not used extensively for some time.

The Portfolio Contents

1. The main page with links to the About Me, Projects, and Artworks pages. The latter two also feature a small selection of my favourite works.

2. The project page with a list of all my projects. Clicking on a project directs the visitor to its dedicated project page.

3. The artwork page featuring a collection of artwork created under my alias, Nite Prime.

4. The about me page, which provides some information about me and contains my CV.

5. The contact page with my contact information.
