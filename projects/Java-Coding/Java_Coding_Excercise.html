Java Coding Excercise

Tags: java, coding, games, processing

Processing is a program for simple coding, especially made for those learning to code in Java. I used Processing while at university to get familiar with some coding principles, which helped me a lot in later projects.

After doing the small exercises, I was able to create a mini game where you click on falling Space Invaders to collect them. After collecting enough, you try to stop a big boss invader from reaching the end.

The exercises

Click on this DOWNLOAD button to get the files. The files in the ZIP contain the following small programs, the free programm Processing is needed to execute them:

• A Space Invaders-like mini game.
• Boids moving through a generated field grid, determining their path.
• A rotating cube calculated in 2D to appear 3D.
• A tree generated randomly using recursion.
• Moving dots using recursion, moving in a mesmerizing way.
• A simple program creating a batch of polar roses.
• Using a particle system to resemble moving smoke.
• Circles growing until they touch, then slowly dying.
• A program that pixelates an image into differently sized circles.
• Randomly generated Space Invaders being attracted or repelled by the cursor.
