Java Coding Excercise

Tags: java, coding, games, processing

Processing is a programming environment designed to make learning Java and basic programming concepts more accessible. I used Processing at university to familiarize myself with fundamental programming principles, which later proved useful in my other projects.

After completing the smaller exercises, I was able to put what I had learned into practice by creating a small game in which the player clicks on falling Space Invaders to collect them. After collecting enough of them, the player must prevent a large boss invader from reaching the end of the level.

The Exercises

Click on this DOWNLOAD button to get the files. The ZIP contains the following small programs. The free programming environment Processing is required to run them:

• A Space Invaders-like mini game.
• Boids moving through a grid and determining their own paths.
• A rotating cube calculated entirely in 2D to create the appearance of 3D.
• A randomly generated tree created using recursion.
• Moving dots using recursion to create mesmerizing patterns.
• A simple program generating a collection of polar roses.
• A particle system designed to resemble moving smoke.
• Circles that grow until they touch and then slowly disappear.
• A program that pixelates an image using circles of different sizes.
