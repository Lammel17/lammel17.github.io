Ester Character

Tags: 3d, blender, character-modeling, retopology, texturing, rigging, animation, marvelous-designer

Like in my previous 3D modeling project, Coast Guard, I started creating this character from a sketch I made, but intended to finish it with a short animation.

I started by modeling the base and then retopologized it. I then tried Marvelous Designer to simulate the clothes, with satisfying results.

The Process

I recycled the base mesh of the Coast Guard into a more feminine body. After that, I did the retopology and modeled some of the clothes, such as the boots. I paid especially close attention to the joint areas, knowing that I would use the model for an animation, which requires the mesh to bend realistically.

Marvelous Designer is especially useful for creating realistic cloth by simulating folds using physics. In Substance Painter, I textured the model, and the hair was created using Geometry Nodes.

Animation

The animation is rather simple, but weight painting the body, cloth, and face was a bit of a process, as it was my first time really figuring that out.
