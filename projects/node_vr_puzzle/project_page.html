Node: VR Puzzle Game

Tags: vr, coding, game-design, puzzle, unity, blender

Node is a VR game designed for the Meta Quest 2 and developed as part of a group project.

I worked on the puzzle concepts and wrote the code to implemented them in Unity. I was also responsible for many of the game's assets, including modeling and texturing, which I created in Blender.

About the game

You play as a lonely traveler searching for a new home. The player starts at the edge of a desert, facing a wall of mountains with an old factory hidden inside one of them. The game begins as you enter the factory, hoping to find a better place on the other side of the mountains.

The main feature of the game is an X-ray projector, which the player can use to see through walls, revealing hidden mechanisms and clues that help solve the puzzles.
