Lend A Hand | Animation

Tags: animation, hand-drawn, hand, frame-by-frame

This is a short frame by frame animation I drew myself in Clip Studio Paint. It is about a hand as main character, being annoyed by a fly inside a museum. They start to fight, but at the end are able to become friends. In that process of drawing an dynamic animation I was able to improve myself very fast, by my estimation. But it would be an overstatement that I was a efficient animator by the end. But I still liked the process and outcome of this short project.
