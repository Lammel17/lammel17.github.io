Innovil: A Souls-Like Boss Fight

Tags: unity, 3ds-port, demake, souls-like

Innovil is a Souls-like boss fight that I developed entirely from the ground up. You can see the original Innovil game here. When developing Innovil, I secretly hoped that it could one day be played on my favourite handheld gaming console, the Nintendo 3DS. With the help of the 3DS modding community, I was able to create a build for the handheld, allowing me to play a Souls-like on the go in stereoscopic 3D.

Click on this GitHub link to visit the GitHub release page, where you can download the game. The game is only playable on a modded New 3DS, or potentially through an emulator such as Citra.

The Demake of Innovil

The 3DS is very limited in terms of performance, so I had to compress files, remove lighting, and replace all the textures. This taught me a lot about optimization and led me to develop some interesting solutions for simulating shadows and dynamic clouds. Through many iterations, I was able to achieve a stable frame rate of 40–60 FPS. There is also a toggle that allows the player to switch the background between dark, light, and empty variants, which can help squeeze out a few more frames per second.
